# Self Media Library: real visual analysis and semantic workspace

Tracking REQ-20261020-0003. Additive to the existing five-tab independent app.

## Implemented contract

Pinned CPU int8 CLIP vision/text encoders (153.6 MB weights plus 2.2 MB tokenizer), 512-dimensional normalized embeddings; one inference subprocess, two intra-op threads, 1.5 GB RSS watchdog, bounded batches and job timeouts. No GPU, PyTorch or vector database required. Model files persist in the app's protected data directory, are hash-verified during preparation and are reused across immutable releases.

Every image or clip is analyzed from decoded pixels; video uses three timestamped samples. SQLite stores versioned vectors, structured candidate scores, provider/model/timestamps, quality measurements, contact sheets and human overrides. Filename fallback no longer marks visual inference complete. Automatic analysis is isolated from web requests; durable jobs support restart recovery, cancellation and bounded manual retries. Search text embeddings are generated by the worker and cached by model version and query. Small-catalog vector search is bounded to 5,000 active assets; duplicate review to 200 displayed candidates.

AI Search supports text-to-media and reference/existing-image similarity, compound technical/content/review/date/usage filters, saved dynamic searches, grid/list previews, editable metadata, confidence/source display, change history, usage history and bulk review/tags. Manual fields override generated suggestions and are indexed separately without replacing visual vectors. Deleted assets are excluded immediately; old model versions are excluded from semantic search until reanalysis.

Ranking after filters: 85% visual/text cosine, 10% advisory visual quality, 5% metadata overlap. Manual text embeddings can improve relevance. CLIP is a retrieval/classification model; the description is a transparent summary of candidate suggestions rather than a fabricated free-form caption. Candidate-relative scores are **not calibrated probabilities**. Objects outside the fixed label set, negation, fine actions, lighting, mood and complex relationships can be wrong. Human review is required. Face identity/clustering remains disabled; no sensitive traits are inferred.

Near-duplicate recommendations require both dHash distance <=6 and CLIP cosine >=0.93, remain review-only, and prefer quality then resolution. Sharpness, blank-frame fraction and dominant palettes are measured from decoded pixels; no media is removed by the AI worker. Actual source/clip IDs and timestamps remain intact.

The existing machine API adds explicit `semantic=true` / `semantic: true` opt-in. Semantic delivery requires approved, rights-confirmed assets and the existing server-side editor token. Reservations preserve per-project no-repeat, same-scene retry idempotence, adjacent-source diversity, commit/release idempotence and expiry checks. Existing Scene Builder selection behavior is unchanged; no global consumer flag is enabled.

Original-source cleanup now also requires a verified full-original Drive archive, separately retrieved SHA-256 readback, verified derived outputs and no active AI/downstream lease. Model caches, databases, approved assets and credentials remain protected. App-owned cleanup status is exposed at `/api/v1/ai/cleanup/status`. No central cleanup executor is added.

## Operational dependencies and remaining register

Live pre-change evidence: 4 CPU cores, 7.6 GB RAM (2.2 GB used), 45.7 GB free disk; Drive and editor token unconfigured. Local AI requires no external secret. Drive remains disabled until a configured identity and real read/write/readback proof; editor consumer activation remains blocked by its existing missing token. No credentials are generated, displayed or transferred.

This release covers the usable visual-analysis/search/metadata/review/delivery foundation. It does not claim completion of all 75 approved items. Verified object bounding boxes, reliable temporal camera/action models, automatic crop application, opt-in face clustering, full remote folder browsing, resumable byte-level downloads and full Scene Builder consumer rollout require subsequent independently verified work. Their UI/status must not present heuristic guesses as implemented capabilities. Static-frame CLIP action/shot/mood labels are explicitly uncertain suggestions.

## Evidence and rollback

`tests/test_self_media_library_ai.py`: unavailable behavior, persistence, human precedence, edit conflicts, trash invalidation, editor authentication, jobs, reservations, collections and real controlled vision/semantic/video checks. `production/sml_ai_verify.py` exercises the actual worker, SQLite and APIs against tiger, mountain-lake and city samples with opaque filenames in a disposable catalog; it never reads production data. `production/sml_ai_browser_test.py` exercises all five tabs, upload, metadata and unavailable/error states at 360, 768 and 1366 px. Existing integrity, metadata and Drive cleanup regressions remain required.

Guarded release prepares weights and verifies real inference before cutover; app idle checks, SQLite/WAL backups and existing rollback pointer/unit journals remain enabled. Migrations are additive; original source IDs/files and existing tables stay intact. Auto Script stays offline and unrelated services are not deployed.

## Primary model provenance

- Original OpenAI CLIP and MIT license: https://github.com/openai/CLIP
- Pinned ONNX conversion: https://huggingface.co/Xenova/clip-vit-base-patch32/tree/d15189d7028b43f1d3e65039190477f6af591c2a
- Hugging Face zero-shot image-classification reference: https://github.com/huggingface/transformers/blob/main/docs/source/en/tasks/zero_shot_image_classification.md
- Controlled test media: https://huggingface.co/datasets/Xenova/transformers.js-docs

No model weights, external images, secrets or user media are committed to the repository.

Local text analysis: Tesseract English OCR with word confidences; pinned MIT Systran/Whisper tiny multilingual int8 speech model (75.5MB) runs in the same isolated worker only for media with audio. Transcripts cover up to the first 30 seconds per asset and explicitly report truncation; 2–4s clips are fully covered. OCR/transcript text is indexed separately in the same embedding space. Unavailable/failed text recognition does not prevent visual analysis. Speech errors and language accuracy require human correction. Verified against rendered known text and the public-domain JFK sample from ggml-org/whisper.cpp; no real user media used. Tesseract is Apache-2.0; faster-whisper and model weights MIT.

Ingest/scene continuation: local folder selection uploads images/videos recursively through existing APIs; up to 32 authorized URL requests persist in a serialized import queue, recover after restart and support failed-request retry. This is durable request recovery, not a claim of byte-offset download checkpointing. Adaptive FFmpeg scene candidates use measured scene-score statistics with a bounded 5fps/320px inspection pass and timeout; duration profiles validate 0.5–30 seconds while retaining 2–4s defaults. App-owned housekeeping retries dirty AI sidecars and reevaluates safe source cleanup after AI/downstream jobs finish. Custom metadata and tag-alias JSON editors are included.

Framing/review additions: 16:9, 9:16 and square crop suggestions rank three feasible windows by actual subject/text visual relevance. They are uncertain recommendations with coordinates, never asserted bounding boxes or automatic destructive crops. Visual relationship and possible branding/overlay labels are uncertain model suggestions; watermark/logo alerts require manual rights review and never prove a license or clean image.
